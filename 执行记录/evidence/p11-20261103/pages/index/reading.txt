Java 虚拟机原理

原理 · 源码 · 图解 · 证据

从类文件到运行时

以 Java 虚拟机（Java Virtual Machine，JVM）的运行机制为线索，理解程序如何被加载、执行、优化、暂停与回收。

本书面向具备 Java 编程基础、了解线程与集合的读者。技术基线为 Java 开发工具包（Java Development Kit，JDK）25 与 OpenJDK HotSpot；规范、具体实现和本机观察分别说明。

可从第 1 章贯穿程序开始，沿第一篇建立运行和源码观察方法，再在第二篇追踪类文件、验证、身份、初始化与元数据存活，进入第三篇理解进程内存、对象布局、分配和本地资源所有权，再沿第四篇追踪调用、编译、优化与恢复，并在第五篇连接安全点、屏障与各收集器的实际工作，继而在第六篇依据同步关系解释线程、监视器、虚拟线程与任务作用域，再在第七篇分析启动共享、缓存训练和本地资源边界，最后在第八篇串联诊断接口、事件时间线、故障推理与性能口径。也可从第 4 章类文件样章独立阅读。全书由八篇、三十六章与六个附录组成，可按章顺读，也可沿附录中的路线阅读。

本轮示例使用 Homebrew OpenJDK 25.0.5.0.2，macOS AArch64。书内必要图文和代码片段支持本地离线阅读；外部规范与源码链接用于追溯。普通构建见第 4 章运行说明；含布局章的聚合构建先按第 10 章说明安装随书固定布局工具。
