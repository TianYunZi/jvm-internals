第23章运行说明

返回正文 · 源码阅读

容量单位采用兆二进制字节（mebibyte，MiB）和千二进制字节（kibibyte，KiB）。本章观察垃圾收集（Garbage Collection，GC）机制。

Java开发工具包（Java Development Kit，JDK）25.0.5.0.2，HotSpot、macOS AArch64。CH23-E01 ConcurrentCycleJourney：12 MiB长期载荷，2 MiB最近载荷，48批共192 MiB短命载荷；中间释放一半长期持有，两次回收请求。用户“执行P06”授权普通教学源码及有界机制观察；没有测试、断言、压力、性能基准或主动资源耗尽。

完整命令

在项目根目录执行。编译只编译，不自动运行；结束后进程正常退出，必要时可用终端中断停止。

export JAVA_HOME=/opt/homebrew/Cellar/openjdk@25/25.0.5.0.2/libexec/openjdk.jdk/Contents/Home
export PATH="$JAVA_HOME/bin:/opt/homebrew/bin:$PATH"
mvn -B -ntp -pl chapters/ch23-zgc -am compile
java -Xms128m -Xmx128m -XX:ActiveProcessorCount=2 -XX:ParallelGCThreads=2 -XX:ConcGCThreads=1 -XX:+UseZGC '-Xlog:gc*:file=chapters/ch23-zgc/evidence/runs/ch23-20261103-01/zgc.log:uptimemillis,level,tags' -cp chapters/ch23-zgc/target/classes org.example.jvminternals.ch23.ConcurrentCycleJourney

实际记录与边界

只有macOS AArch64与当前发行版已实测；分配停顿没有被故意制造，没有性能排名或业务尾延迟保证；当前数据不足以确定其他负载的最小安全堆容量。
