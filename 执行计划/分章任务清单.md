# 图文书分章任务清单

本清单落实[执行总计划](../执行计划.md)，覆盖 Java 虚拟机（Java Virtual Machine，JVM）原理书的 36 章和附录 A—F。技术基线为 Java 开发工具包（Java Development Kit，JDK）25，最终正文采用超文本标记语言（Hypertext Markup Language，HTML）。

**本清单定义后续内容工作，不表示已经生成正文、源码或实验结果。** 第 4 章工作区已预建，内容实施状态见 [第 4 章任务单](../chapters/ch04-classfile/TASK.md)；其他章节与附录按任务推进建立。公共阶段状态见 [公共任务记录](../执行记录/公共任务.md)。

## 清单使用规则

1. 表中的章节范围包括对应分纲范围内的全部三级编号要点。执行者必须逐项建立覆盖映射；表内突出任务与专属验收，不缩减原分纲。
2. 每章的规范链接、源码入口以所链接分纲的“源码阅读计划”及相关正文为起点。研究时进一步定位到锁定源码的文件、符号、条件及协作关系，登记在本章证据索引。
3. 全部章节默认交付本章 `TASK.md`、`README.md`、`chapter.html`、图源与显示图、证据索引；有代码生成需求时补充源文件和必要构建材料。观察型章节可明确复用已有源码。
4. 所有章节同时满足总计划 C01—C08。下表“专属验收”是额外的本章要求，不能替代通用验收。
5. 源码、观测、故障复现、微基准等分别登记授权状态。表内列出任务不等于已获测试代码授权；具体处理遵循总计划第二节。
6. 目录均为相对项目根目录的目标路径，是否已创建以实际文件为准。前置编号指需要理解或核查的材料，不一律要求前置章节全文完稿；主执行顺序见总计划 P00—P11。
7. 所有章节和附录中需要配图说明的内容，必须实际绘制：一般原理插图使用可缩放矢量图形（Scalable Vector Graphics，SVG），软件工程相关的架构、类与模块关系、交互、流程及状态图使用 Mermaid。逐节登记配图需求与绘制方式；SVG 保留可编辑文件，Mermaid 保留 `.mmd` 图源并本地导出 `.svg` 供正文离线显示。分纲未单列但实际需要图解的内容也纳入清单，截图或未渲染的 Mermaid 文本不能代替教学插图。
8. 所有章节和附录涉及代码展示时统一使用 Shiki，包括代码块、代码片段和源码阅读页；配置与命令示例按实际语言处理。按公共基线生成静态高亮 HTML，保留真实代码文本与源文件定位；验收检查实际生成记录、语言与主题、复制、窄屏和打印可读性，不以样式类名或截图代替 Shiki 高亮。

### 第 4 章样章的任务拆分

样章使用与其余章节相同的正式路径，不另建最终会被遗弃的样章副本。以下步骤在本章任务单中分别记录：

1. `CH04-R`：读取总纲 4.1—4.5 和分纲所有对应三级要点，核对规范结构、源码入口及接口版本，建立覆盖表和示例清单。
2. `CH04-C`：生成清单中的教学源码和最小构建，确认生成与变换产物不会覆盖源文件；按授权执行必要编译和观察。
3. `CH04-E`：保存编译条件、反汇编结果、接口使用记录和实现定位，区分原始输出与人工标注。
4. `CH04-H`：先完成代表性图文页面，再完成全部正文和三类图解主题；源码、代码片段和图中标注保持一致。
5. `CH04-A`：按 C01—C08 验收整章，修正页面和内容；将可复用样式与约定交给公共任务维护。

这五步是同一章的阶段，状态保存在同一份 `TASK.md`，不再创建五份并行状态文件。样章需要的实验授权若不足，记录阻塞并完成可继续部分，不以演示数据替代正式证据。
