# 第四篇 执行引擎与动态编译

《jvm原理》分篇大纲，覆盖第 13—18 章。基于 Java 开发工具包（Java Development Kit，JDK）25，解释 Java 虚拟机（Java Virtual Machine，JVM）如何执行字节码、选择调用目标、生成机器码并恢复失效的优化假设。章、节编号与[全书大纲](../大纲.md)对应。

## 本篇目标与前后衔接

本篇沿“解释执行 → 方法调用 → 动态链接 → 分层编译 → 优化 → 去优化”展开。读者应能将一个方法的执行现象关联到编译画像、编译决策和运行时状态。

- 前置知识：字节码、类型元数据、对象分配、调用栈与基本处理器知识。
- 核心成果：调用目标选择图、方法执行形态迁移图、优化与恢复的完整案例。
- 衔接：本篇说明编译器如何利用运行时信息；第五篇说明生成代码如何配合垃圾收集，第六篇说明并发语义如何限制优化。

分层编译与逃逸分析的背景可参照 [JDK 25 HotSpot 性能增强说明](https://docs.oracle.com/en/java/javase/25/vm/java-hotspot-virtual-machine-performance-enhancements.html)，具体优化决策以锁定版本的源码及编译记录解释。

## 第 13 章 解释器、栈帧与异常执行

**核心问题：解释器怎样让一条条字节码形成完整的方法执行过程？**

### 13.1 栈式模型与模板解释器

- 13.1.1 将规范中的操作数栈和局部变量映射到 HotSpot 解释执行状态。
- 13.1.2 解释模板解释器生成本地执行片段的方式，区分字节码指令与承载其语义的机器指令。

### 13.2 入口、分派与模板生成

- 13.2.1 串联方法入口、字节码定位、模板分派和下一条指令选择。
- 13.2.2 对照普通执行、运行时辅助调用与异常路径，说明共享实现和架构相关模板的关系。

### 13.3 栈帧建立与遍历

- 13.3.1 分析参数、局部变量、操作数栈、返回地址及调用者状态的保存。
- 13.3.2 区分逻辑调用栈和物理栈帧，为内联后的栈恢复和诊断栈遍历建立基础。

### 13.4 异常传播

- 13.4.1 追踪异常对象、当前方法处理器查找和调用链逐层展开。
- 13.4.2 区分显式抛出、运行时检查引发的异常与处理器缺失时的退出路径。

### 13.5 不同执行形态之间的转换

- 13.5.1 描述解释器与编译后代码之间的调用适配。
- 13.5.2 概述 Java 与本地代码的调用转换和状态保存，将完整互操作机制留到第七篇。

**图解安排：**解释器循环图、解释栈帧图、异常查找与展开时序图。

## 第 14 章 方法调用与动态分派

**核心问题：一条调用指令怎样确定当前真正要执行的方法？**

### 14.1 调用指令分类

- 14.1.1 对照静态、特殊、虚和接口调用的接收者及语义。
- 14.1.2 将重载选择、覆盖关系和运行时分派放到各自发生的阶段。

### 14.2 解析、选择与目标

- 14.2.1 沿符号引用解析说明方法查找及访问检查。
- 14.2.2 使用不同接收者类型说明已解析方法和最终调用目标的关系。

### 14.3 方法表与调用点缓存

- 14.3.1 解释虚方法表、接口方法表及对应查找路径。
- 14.3.2 分析调用点缓存如何记录类型与目标，以及未命中时如何转入运行时处理。

### 14.4 接收者类型分布

- 14.4.1 描述单态、多态和多态程度较高的调用点，解释类型画像如何形成。
- 14.4.2 分析运行阶段变化及新类型出现对既有调用策略的影响。

### 14.5 去虚化与内联

- 14.5.1 说明静态类型信息、类层次和运行时画像可提供哪些优化依据。
- 14.5.2 区分有保证的目标确定和带守卫的推测优化，并引出假设失效后的恢复。

**图解安排：**方法解析与选择图、调用点缓存状态图、类型画像与去虚化关系图。

## 第 15 章 动态调用、反射与运行时生成

**核心问题：动态语言特性和框架调用怎样建立可被优化的执行路径？**

### 15.1 方法句柄与类型适配

- 15.1.1 说明方法类型、方法句柄及调用适配链的组成。
- 15.1.2 对照精确调用与可适配调用，解释参数转换、返回值和组合操作。

### 15.2 动态调用点链接

- 15.2.1 从 `invokedynamic` 的类文件信息进入引导方法，再建立调用点与目标。
- 15.2.2 分析首次链接、后续调用和可变调用点的约束，说明动态性如何与优化并存。

### 15.3 动态常量

- 15.3.1 对照动态常量与动态调用点，区分被解析的是值还是调用行为。
- 15.3.2 分析解析结果、异常与依赖关系，关联运行时常量池生命周期。

### 15.4 Lambda 与字符串拼接

- 15.4.1 将 Lambda 捕获信息、引导方法和生成的实现结构对应起来。
- 15.4.2 分析字符串拼接的调用点建立和参数适配，区分语言语义与某一版本的生成策略。

### 15.5 反射、代理与运行时类生成

- 15.5.1 追踪反射调用和动态代理从入口到实际目标的关键环节。
- 15.5.2 将隐藏类、方法句柄与动态生成结构联系起来，讨论访问控制和缓存造成的生命周期影响。

**图解安排：**动态调用首次链接时序图、方法句柄适配链图、Lambda 捕获关系图。

## 第 16 章 即时编译与分层执行

**核心问题：虚拟机为什么在运行中编译，何时值得编译一个方法？**

### 16.1 即时编译的收益与成本

- 16.1.1 说明即时编译（Just-in-Time Compilation，JIT）如何利用当前运行的信息生成机器码。
- 16.1.2 比较编译时间、代码空间、画像开销和后续执行收益。

### 16.2 两类 HotSpot 编译器

- 16.2.1 介绍客户端编译器（Client Compiler，C1）与服务端编译器（Server Compiler，C2）的职责和取舍。
- 16.2.2 说明收集画像的编译代码、较快生成的代码与更深度优化代码之间的关系。

### 16.3 热点计数与运行画像

- 16.3.1 分析方法进入次数、循环回边和类型画像提供的信息。
- 16.3.2 说明计数、采样和决策并非源码层面固定不变的简单阈值规则。

### 16.4 编译调度与层级转换

- 16.4.1 展开编译请求、队列、线程、优先级和执行入口更新。
- 16.4.2 用状态迁移说明可能的层级路径及资源压力影响，避免将每个方法都描述为顺序经历全部层级。

### 16.5 启动、预热与稳定阶段

- 16.5.1 将画像收集、编译活动与业务执行的时间线关联。
- 16.5.2 讨论负载变化、短生命周期进程和稳定性能形成条件，连接第七篇的启动与预热优化。

**图解安排：**编译请求处理图、分层执行状态图、业务与编译活动时间线。

## 第 17 章 编译器如何优化 Java 程序

**核心问题：编译器怎样改变执行步骤，同时保持程序允许观察到的语义？**

### 17.1 中间表示与数据依赖

- 17.1.1 介绍中间表示（Intermediate Representation，IR）与静态单赋值（Static Single Assignment，SSA）。
- 17.1.2 用控制、数据和内存依赖说明优化图的作用，比较 C1 与 C2 的表示和处理流程。

### 17.2 基础优化与内联

- 17.2.1 通过小例子连接常量传播、公共子表达式和死代码消除。
- 17.2.2 解释内联如何暴露进一步优化机会，以及代码膨胀、编译预算和调用形态带来的限制。

### 17.3 对象与锁优化

- 17.3.1 从逃逸关系推导标量替换、分配消除和锁消除的可能性。
- 17.3.2 分析锁粗化、异常路径和去优化状态保存的成本，说明优化存在失败条件。

### 17.4 循环、向量化与内建函数

- 17.4.1 说明循环展开、范围检查消除和循环形态变换的依据。
- 17.4.2 区分自动向量化和内建函数替换，讨论架构能力、别名关系及数据依赖造成的限制。

### 17.5 从优化图到机器码

- 17.5.1 串联指令选择、调度、寄存器分配与溢出到栈。
- 17.5.2 对照 x86-64 与 AArch64 的输出，解释相同语义为何形成不同指令序列。

**图解安排：**优化前后依赖图、逃逸关系图、循环转换与机器码对应图。

## 第 18 章 推测优化、去优化与代码生命周期

**核心问题：优化后的假设不再成立时，虚拟机怎样继续正确执行？**

### 18.1 优化假设及其依赖

- 18.1.1 说明类层次、调用类型和分支画像怎样成为优化依据。
- 18.1.2 区分运行时守卫和依赖记录，分析新增类型或行为变化如何触发失效。

### 18.2 罕见陷阱与去优化触发

- 18.2.1 解释将少见路径交回运行时处理的策略及其收益。
- 18.2.2 将陷阱原因、代码失效和重新编译联系起来，分析频繁变化带来的代价。

### 18.3 恢复解释执行状态

- 18.3.1 说明优化中被合并或消除的局部变量、逻辑栈帧如何被恢复。
- 18.3.2 分析标量替换对象的物化以及恢复时需要保留的元数据。

### 18.4 长循环与执行方式切换

- 18.4.1 介绍栈上替换（On-Stack Replacement，OSR），解释运行中的长循环如何进入编译后代码。
- 18.4.2 区分 OSR 编译入口、普通方法入口和去优化恢复方向。

### 18.5 编译代码的生命周期

- 18.5.1 关联编译代码对象、依赖、栈上活动和代码缓存管理。
- 18.5.2 说明不可进入、仍被活动栈引用及最终可回收的差异，分析代码缓存压力。

**图解安排：**优化假设失效时序图、内联栈重建图、代码对象生命周期图。
