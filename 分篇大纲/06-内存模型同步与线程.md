# 第六篇 内存模型、同步与线程

《jvm原理》分篇大纲，覆盖第 25—29 章。基于 Java 开发工具包（Java Development Kit，JDK）25，分析 Java 虚拟机（Java Virtual Machine，JVM）如何保证共享数据的语义，以及平台线程、监视器和虚拟线程如何运行。章、节编号与[全书大纲](../大纲.md)对应。

## 本篇目标与前后衔接

本篇从语言层的可见性和顺序规则进入线程与锁的实现，再解释虚拟线程及其上下文管理。读者应能够区分语言保证、操作系统调度行为和某次运行观察。

- 前置知识：处理器内存顺序、栈帧、对象头、编译优化和安全点。
- 核心成果：并发关系图、监视器状态图、虚拟线程挂载与卸载图。
- 衔接：第五篇解释回收一致性，本篇解释应用共享数据的并发语义；第八篇负责综合故障定位。

并发正确性的基础来自[语言规范第 17 章](https://docs.oracle.com/javase/specs/jls/se25/html/jls-17.html)。观测到某个结果只能说明该次执行发生了什么，不能代替对所有允许执行的规则推理。

## 第 25 章 Java 内存模型

**核心问题：一个线程写入的数据，另一个线程什么时候有权观察到？**

### 25.1 内存模型与内存区域

- 25.1.1 介绍 Java 内存模型（Java Memory Model，JMM）的职责：规定共享变量访问与允许的执行行为。
- 25.1.2 区分并发语义和堆、栈等存储区域，说明“存放在何处”不能单独回答“何时可见”。

### 25.2 原子性、可见性与顺序性

- 25.2.1 通过读写、复合更新和检查后执行等操作分别讨论三种性质。
- 25.2.2 定义数据竞争，区分正确同步、无锁算法与没有同步保证的普通共享访问。

### 25.3 happens-before 推理

- 25.3.1 组织程序顺序、同步动作与传递关系，建立推导跨线程可见性的步骤。
- 25.3.2 对照同步顺序与现实时间先后，解释“更早发生”不自动建立可见性保证。

### 25.4 关键语言机制

- 25.4.1 分析 `volatile`、锁、线程启动和结束协作所建立的关系，说明复合操作仍需整体原子性。
- 25.4.2 介绍 `final` 字段语义、构造期间逸出和安全发布，并区分引用不可变与对象内容不可变。

### 25.5 从语义到实现

- 25.5.1 说明编译器如何保留必要的内存依赖、限制重排并选择屏障。
- 25.5.2 对照 x86-64 与 AArch64 的实现，区分规范保证和某架构恰好提供的更强行为。

**图解安排：**并发动作与关系图、安全发布时序图、语言规则到机器指令的对应图。

## 第 26 章 平台线程与 HotSpot 线程运行时

**核心问题：Java 线程状态如何关联到运行时状态、调度和资源占用？**

### 26.1 线程对象与执行实体

- 26.1.1 区分 Java `Thread` 对象、HotSpot 线程结构及操作系统线程。
- 26.1.2 介绍虚拟机内部线程的职责，说明并非所有本地线程都代表应用 Java 线程。

### 26.2 生命周期与资源

- 26.2.1 串联创建对象、启动执行、进入运行时、终止和资源回收。
- 26.2.2 分析线程栈、本地线程资源与异常退出，连接第三篇的内存预算。

### 26.3 不同层次的状态

- 26.3.1 对照 Java 状态、HotSpot 内部状态和操作系统调度状态。
- 26.3.2 解释可运行不等于正在使用处理器，以及本地调用中的状态为何需要结合栈和系统信息判断。

### 26.4 阻塞、中断与许可

- 26.4.1 分析 `park`、`unpark` 的许可语义，区分唤醒请求与实际获得运行机会。
- 26.4.2 讨论中断状态、可中断阻塞和虚假返回，说明中断是协作信号而非强制终止。

### 26.5 线程转储与调度成本

- 26.5.1 将线程数量、栈信息、等待对象及操作系统状态组合用于定位。
- 26.5.2 分析调度延迟、频繁切换和过量线程的代价，说明单份转储的时间快照局限。

**图解安排：**三层线程关系图、生命周期图、许可与阻塞时序图。

## 第 27 章 synchronized 与锁的实现

**核心问题：监视器语义怎样落实到对象状态、竞争管理和线程停放？**

### 27.1 同步语义与字节码

- 27.1.1 对照同步块、同步方法、重入及正常与异常释放路径。
- 27.1.2 将互斥与内存可见性分别解释，明确获取和释放监视器带来的语义。

### 27.2 轻量级路径与膨胀

- 27.2.1 按 JDK 25 的默认实现分析无竞争获取、重入、退出和竞争转入慢路径。
- 27.2.2 区分轻量级锁状态和对象监视器，解释膨胀的用途及与旧版本锁实现的不同。

### 27.3 原子操作、自旋与阻塞

- 27.3.1 介绍比较并交换（Compare-and-Swap，CAS），说明原子竞争更新及失败重试。
- 27.3.2 分析自旋、排队、停放和唤醒的成本，区分可伸缩性与公平性。

### 27.4 等待与通知

- 27.4.1 推演 `wait` 释放监视器、进入等待集合及返回前重新获取监视器的过程。
- 27.4.2 分析通知、中断、超时和虚假唤醒，说明为何条件判断必须和等待循环配合。

### 27.5 监视器收缩及对象头协作

- 27.5.1 分析空闲监视器的生命周期和回收条件，区分对象回收与监视器资源回收。
- 27.5.2 讨论身份哈希与紧凑对象头对锁状态保存的影响，关联第三篇的布局设计。

### 27.6 类库锁与运行时原语

- 27.6.1 介绍抽象队列同步器（AbstractQueuedSynchronizer，AQS）怎样组合状态字段、队列与停放原语。
- 27.6.2 对照 `ReentrantLock` 与内置监视器，区分类库策略和虚拟机提供的基础能力。

**图解安排：**监视器进入退出图、竞争与等待集合图、锁状态和对象头协作图。

## 第 28 章 虚拟线程的运行机制

**核心问题：大量 Java 线程怎样复用较少的操作系统线程而保持线程语义？**

### 28.1 线程、载体与调度器

- 28.1.1 区分虚拟线程身份、载体线程和实际执行它的操作系统线程。
- 28.1.2 说明任务进入调度器、获得载体和再次排队的过程，区分并发规模与执行速度。

### 28.2 延续与栈块

- 28.2.1 解释暂停执行时保存何种状态，以及栈冻结、恢复与栈块的关系。
- 28.2.2 分析解释帧、编译帧和栈遍历的协作，连接第四篇的帧表示。

### 28.3 挂载、卸载与阻塞适配

- 28.3.1 沿一次可卸载的阻塞操作，追踪载体释放、就绪通知和恢复执行。
- 28.3.2 区分已适配阻塞、无法释放载体的等待和处理器密集执行，说明调度能力的边界。

### 28.4 与其他子系统协作

- 28.4.1 说明垃圾收集（Garbage Collection，GC）如何处理栈块及其中的引用。
- 28.4.2 分析线程局部数据、调试栈和本地调用对虚拟线程资源及可观察性的影响。

### 28.5 JDK 25 中的固定问题

- 28.5.1 采用 JDK 25 的监视器协作行为解释同步代码，不沿用旧版本关于 `synchronized` 必然固定载体的概括。
- 28.5.2 分析本地方法和外部函数相关固定场景，区分固定事件、载体占用与业务瓶颈。

本地方法和外部函数仍是需要分析的固定来源；虚拟线程提高的是适用负载下的并发承载能力。[JDK 25 虚拟线程指南](https://docs.oracle.com/en/java/javase/25/core/virtual-threads.html)

**图解安排：**挂载与卸载时序图、栈冻结与恢复图、固定场景的载体占用图。

## 第 29 章 作用域值与结构化并发

**核心问题：线程数量和任务关系变化后，怎样明确上下文及子任务的生命周期？**

### 29.1 线程局部数据

- 29.1.1 说明线程局部映射的持有关系、清理时机及长期线程上的残留风险。
- 29.1.2 分析海量短生命周期线程下的数据复制和初始化成本。

### 29.2 作用域值

- 29.2.1 展开 `ScopedValue` 的绑定、读取、嵌套重绑定与作用域退出。
- 29.2.2 区分绑定不可变与被绑定对象是否可变，并说明上下文向子任务传递所需的结构条件。

### 29.3 结构化任务生命周期

- 29.3.1 分析任务作用域、拥有者、子任务、等待完成和关闭的关系。
- 29.3.2 讨论失败、超时、取消和中断响应，说明发出取消请求不等于子任务已退出。

### 29.4 类库与运行时支持

- 29.4.1 追踪作用域和虚拟线程的结合，说明任务结构如何影响上下文持有。
- 29.4.2 将任务树、调用栈和线程视图对应，解释结构信息对诊断的价值。

### 29.5 JDK 25 接口形态与状态

- 29.5.1 将应用程序编程接口（Application Programming Interface，API）的正式和预览状态分别记录。
- 29.5.2 固定使用 JDK 25 的作用域创建、任务派生和汇合接口，避免混用早期预览版的形态。

`ScopedValue` 为正式 API，结构化并发为第五次预览。[ScopedValue 文档](https://docs.oracle.com/en/java/javase/25/docs/api/java.base/java/lang/ScopedValue.html)、[StructuredTaskScope 文档](https://docs.oracle.com/en/java/javase/25/docs/api/java.base/java/util/concurrent/StructuredTaskScope.html)

**图解安排：**上下文绑定嵌套图、父子任务树、失败与取消传播图。
