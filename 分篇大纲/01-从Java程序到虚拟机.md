# 第一篇 从 Java 程序到虚拟机

《jvm原理》分篇大纲，覆盖第 1—3 章。基于 Java 开发工具包（Java Development Kit，JDK）25，以 HotSpot 解释 Java 虚拟机（Java Virtual Machine，JVM）的整体运行过程。章、节编号与[全书大纲](../大纲.md)对应。

## 本篇目标与前后衔接

本篇建立阅读全书所需的体系结构、计算机基础和源码观察方法。读者应能说明 Java 程序经历哪些执行阶段、运行时如何使用操作系统资源，以及如何从运行现象定位到源码模块。

- 前置知识：能够阅读 Java 类、方法、对象创建及基础线程代码。
- 核心成果：一张虚拟机架构图、一条程序运行时间线、一份可复现的环境记录。
- 内容边界：先建立子系统之间的联系；对象布局、编译优化和回收算法在后续各篇展开。

规范模型以[虚拟机规范第 2 章](https://docs.oracle.com/javase/specs/jvms/se25/html/jvms-2.html)为依据；HotSpot 数据结构和执行策略作为实现层内容单独解释。

## 第 1 章 JVM 的职责与整体架构

**核心问题：一份 Java 源码经过哪些环节，最终成为处理器执行的指令？**

### 1.1 Java 源码、类文件、解释执行与机器码

- 1.1.1 区分源码语言、类文件指令集和硬件指令集，说明各层承载的信息。
- 1.1.2 串联编译、加载、解释、热点识别与动态编译；解释同一个方法可能具有多种执行形态。

### 1.2 JVM、JDK、标准类库与操作系统的职责

- 1.2.1 说明编译器、启动器、虚拟机和标准类库的分工，识别 Java 实现与本地实现之间的边界。
- 1.2.2 以文件访问、线程创建和内存申请为例，追踪运行时对操作系统能力的使用。

### 1.3 虚拟机主要子系统

- 1.3.1 建立类加载、运行时内存、解释器、编译器、线程和垃圾收集器的职责图。
- 1.3.2 选择“创建对象并调用方法”作为协作实例，标出类型信息、分配路径和调用目标之间的联系。

### 1.4 规范、实现与可移植性

- 1.4.1 区分类文件格式、指令语义等规范约束与对象布局、编译策略等实现选择。
- 1.4.2 解释平台可移植性需要满足的条件，包括运行时版本、类库依赖、本地库和环境行为。

### 1.5 从程序启动到退出

- 1.5.1 按时间顺序排列进程启动、运行时初始化、入口执行、稳定运行和退出。
- 1.5.2 在时间线上标注类加载、线程活动、对象分配、编译和回收可能发生的位置，提出后续各篇的问题。

**图解安排：**四层执行关系图、HotSpot 子系统协作图、程序完整生命周期时序图。

## 第 2 章 理解 JVM 所需的计算机基础

**核心问题：处理器和操作系统的哪些机制决定了虚拟机的实现方式与运行成本？**

### 2.1 处理器、寄存器与缓存层次

- 2.1.1 介绍中央处理器（Central Processing Unit，CPU）、寄存器、流水线和分支预测，解释吞吐与指令依赖。
- 2.1.2 说明缓存行、局部性、缓存一致性与伪共享，将抽象对象访问关联到实际内存访问成本。

### 2.2 虚拟内存与物理内存

- 2.2.1 从进程虚拟地址讲到页表、物理页和缺页，区分地址空间存在与页面实际驻留。
- 2.2.2 解释申请、预留、提交、触碰页面和释放的不同效果，为后续进程内存预算建立基础。

### 2.3 进程、线程与调度

- 2.3.1 说明线程共享和独占的资源，以及可运行、等待和被调度执行之间的差别。
- 2.3.2 区分系统调用、用户态与内核态切换、线程上下文切换，分析各自发生的原因。

### 2.4 调用约定与栈布局

- 2.4.1 介绍应用二进制接口（Application Binary Interface，ABI），说明参数、返回值、保存寄存器和对齐要求。
- 2.4.2 将本地函数栈与虚拟机逻辑栈帧对应，说明优化编译可能改变栈帧的物理表示。

### 2.5 内存顺序与架构差异

- 2.5.1 区分编译器优化造成的顺序变化与处理器内存访问顺序，介绍屏障约束的对象。
- 2.5.2 对照 x86-64 和 AArch64 的调用、原子操作与内存顺序实现，为第六篇建立硬件背景。

**图解安排：**虚拟地址转换图、进程资源与线程资源关系图、调用栈与寄存器传参图。

## 第 3 章 建立 HotSpot 源码阅读与观察环境

**核心问题：怎样获得与运行现象相匹配的源码和诊断证据？**

### 3.1 OpenJDK 源码组织

- 3.1.1 识别类库模块、启动器、HotSpot 共享实现、操作系统相关实现和处理器相关实现。
- 3.1.2 建立从 Java 类到本地入口、共享运行时再到机器相关实现的检索顺序。

### 3.2 版本选择与构建配置

- 3.2.1 记录发行版、完整版本、源码标签、工具链和构建选项，解释运行二进制与源码不一致的影响。
- 3.2.2 对照 release、fastdebug、slowdebug 的用途及观测差异，介绍构建、符号信息和调试入口。

### 3.3 参数类型与生效条件

- 3.3.1 区分产品、诊断、实验和开发构建参数，说明参数可见性与构建类型的关系。
- 3.3.2 区分参数默认值、自动选择值和显式设置值，并记录互相约束或不被支持的配置。

### 3.4 基础工具与统一日志

- 3.4.1 用 `javap` 关联类文件和字节码，用 `jcmd` 获取目标进程实际支持的诊断命令。
- 3.4.2 使用统一日志和本地调试器观察阶段转换；说明观测开销、权限与调试构建对结果的影响。

参数与日志写法以 [JDK 25 启动命令文档](https://docs.oracle.com/en/java/javase/25/docs/specs/man/java.html)为准；具体诊断能力通过目标进程的 `jcmd ... help` 获取。[诊断命令说明](https://docs.oracle.com/en/java/javase/25/docs/specs/man/jcmd.html)

### 3.5 从现象定位关键路径

- 3.5.1 从一次类加载和一次对象创建出发，依次定位入口、数据结构、状态条件与后续调用。
- 3.5.2 区分直接调用、生成代码、内建函数和运行时辅助入口，形成带版本信息的源码阅读记录。

**图解安排：**源码目录导航图、观测工具分层图、Java 到本地实现的阅读路线图。
