# 第七篇 启动、预热与本地互操作

《jvm原理》分篇大纲，覆盖第 30—32 章。基于 Java 开发工具包（Java Development Kit，JDK）25，分析 Java 虚拟机（Java Virtual Machine，JVM）的启动与退出、跨次运行的信息复用，以及 Java 和本地代码的协作。章、节编号与[全书大纲](../大纲.md)对应。

## 本篇目标与前后衔接

本篇从进程启动进入类共享和提前处理缓存，再跨越本地调用边界。读者应能拆分启动与预热成本，解释缓存复用的成立条件，并明确跨语言资源的持有和释放责任。

- 前置知识：类加载与连接、元空间、编译画像、线程状态及垃圾收集协作。
- 核心成果：启动时序图、缓存生成与复用流程图、本地资源生命周期图。
- 衔接：第三篇给出内存成本，第四篇解释编译画像；本篇说明这些机制如何跨运行阶段和调用边界协作。

## 第 30 章 虚拟机启动、退出与类数据共享

**核心问题：从启动命令到入口方法，哪些工作能够共享，哪些必须在当前进程完成？**

### 30.1 启动器与运行时初始化

- 30.1.1 追踪命令行与环境配置进入启动器后的处理，区分启动器选项和虚拟机选项。
- 30.1.2 串联虚拟机创建、基础线程、内存、核心类和运行时子系统初始化的依赖。

### 30.2 类加载与入口选择

- 30.2.1 比较类入口、归档入口、模块入口和源码启动所需的准备工作。
- 30.2.2 结合 JDK 25 的实例入口方法，解释入口候选选择、对象构造与方法执行；将语言变化和启动器行为分开说明。

### 30.3 类数据共享的基础机制

- 30.3.1 介绍类数据共享（Class Data Sharing，CDS），说明归档内容、映射与共享目标。
- 30.3.2 区分共享类元数据与当前进程中的可变运行状态，说明共享不消除全部加载和初始化工作。

### 30.4 应用归档与兼容条件

- 30.4.1 对照基础归档、应用归档和动态归档的生成及使用过程。
- 30.4.2 解释版本、类路径、模块和相关运行配置对归档使用的约束，分析未使用归档的原因。

### 30.5 正常退出与异常终止

- 30.5.1 串联非守护线程结束、显式退出请求、关闭钩子及运行时清理。
- 30.5.2 区分正常关闭、立即停止、系统终止和崩溃，说明不能把关闭钩子当作所有退出场景的保证。

启动选项和归档配置按 [JDK 25 启动命令文档](https://docs.oracle.com/en/java/javase/25/docs/specs/man/java.html)整理；实例入口方法的版本归属按 [JDK 25 变更说明](https://docs.oracle.com/en/java/javase/25/migrate/significant-changes-jdk-25.html)说明。

**图解安排：**启动依赖与时序图、归档映射关系图、退出触发与清理路径图。

## 第 31 章 提前处理缓存与方法执行画像

**核心问题：哪些启动和预热工作可以从部署运行转移到事先训练？**

### 31.1 提前处理的目标

- 31.1.1 介绍提前处理（Ahead-of-Time，AOT），按类加载、连接、画像和编译拆分可转移工作。
- 31.1.2 对照“减少当前运行的重复工作”和“改变程序执行模型”，明确缓存优化的能力范围。

### 31.2 训练运行与缓存生成

- 31.2.1 串联训练应用、记录所需信息、生成缓存和部署使用的过程。
- 31.2.2 区分训练覆盖的代码与未覆盖路径，说明运行时仍需处理动态行为。

### 31.3 JDK 25 的命令行流程

- 31.3.1 整理 JDK 25 的常用生成与使用流程，说明简化操作如何组织原有阶段。
- 31.3.2 记录输入文件、生成产物、缓存位置和运行配置，确保训练与部署具有可追溯的对应关系。

### 31.4 画像保存与编译协作

- 31.4.1 解释方法执行画像如何从训练运行保存，并在后续运行提供给即时编译（Just-in-Time Compilation，JIT）。
- 31.4.2 分析画像复用、当前运行观察和推测优化的关系，区分历史画像与已生成的本地机器码。

### 31.5 代表性、适用条件与评估

- 31.5.1 说明训练负载、类库版本和配置变化对缓存价值的影响，规划未命中与负载变化案例。
- 31.5.2 分别比较进程启动、达到可服务状态和进入稳定性能的时点，避免用单个时长代表全部收益。

### 31.6 与独立本地可执行文件的边界

- 31.6.1 从运行时依赖、动态类加载、编译发生时机和产物形式区分技术路线。
- 31.6.2 将 HotSpot AOT 缓存限定在本书实际分析范围，其他运行方式用于澄清概念。

JDK 25 的重点是简化缓存生成命令以及复用方法执行画像。[JDK 25 启动与预热相关说明](https://docs.oracle.com/en/java/javase/25/migrate/significant-changes-jdk-25.html)

**图解安排：**训练到部署的数据流图、缓存内容与运行阶段对应图、启动与预热分段时间线。

## 第 32 章 本地调用与外部内存

**核心问题：离开 Java 托管执行后，怎样保持线程状态、引用和资源生命周期正确？**

### 32.1 本地调用边界

- 32.1.1 介绍 Java 本地接口（Java Native Interface，JNI），说明本地方法链接、参数传递和返回。
- 32.1.2 分析 Java 与本地状态转换、线程附加和分离，区分当前线程专用的调用环境与可跨调用保存的数据。

### 32.2 引用、句柄与可达性

- 32.2.1 区分本地引用、全局引用和弱全局引用的有效期及释放责任。
- 32.2.2 解释句柄如何参与垃圾收集（Garbage Collection，GC）可达性，避免把托管对象地址直接当成长期稳定的本地指针。

### 32.3 本地临界区与对象移动

- 32.3.1 分析数组或字符串访问涉及的复制、直接访问与临界区约束。
- 32.3.2 结合不同收集器说明对象移动、临界区退出和回收协调，避免将某一收集器的策略泛化为 JNI 全部行为。

JNI 引用、线程环境与异常处理以[JDK 25 JNI 设计规范](https://docs.oracle.com/en/java/javase/25/docs/specs/jni/design.html)为依据。

### 32.4 外部函数与内存接口

- 32.4.1 介绍外部函数与内存（Foreign Function & Memory，FFM）应用程序编程接口（Application Programming Interface，API），解释内存段、布局、分配作用域与线程访问条件。
- 32.4.2 区分堆内和堆外内存段，分析访问边界、存活状态及释放后的使用；说明这些约束不能自动保证任意本地代码正确。

内存段、生命周期与链接器的语义以 [JDK 25 外部函数与内存文档](https://docs.oracle.com/en/java/javase/25/docs/api/java.base/java/lang/foreign/package-summary.html)为准。

### 32.5 调用约定、适配与访问控制

- 32.5.1 结合应用二进制接口（Application Binary Interface，ABI）说明符号查找、函数描述、下行调用和上行回调。
- 32.5.2 分析回调存活期、异常边界和本地访问配置，并记录 JDK 25 的具体告警或限制行为。

### 32.6 泄漏、越界与崩溃线索

- 32.6.1 按“谁分配、谁持有、谁释放”追踪本地资源，关联全局引用、缓冲区和回调。
- 32.6.2 将错误线程、问题帧、加载的本地库和资源状态作为诊断线索，连接第八篇的崩溃分析。

**图解安排：**Java 与本地状态转换图、引用句柄与对象关系图、内存段及回调生命周期图。
