# 第二篇 类文件、类型系统与类的生命周期

《jvm原理》分篇大纲，覆盖第 4—8 章。基于 Java 开发工具包（Java Development Kit，JDK）25，说明 Java 虚拟机（Java Virtual Machine，JVM）如何从类文件建立类型和可执行的运行时状态。章、节编号与[全书大纲](../大纲.md)对应。

## 本篇目标与前后衔接

本篇沿“类文件表示 → 字节码验证 → 加载与命名空间 → 连接与初始化 → 运行时元数据”展开。读者应能够解释类型身份、初始化时机和常见链接错误，并从元数据关系理解类卸载条件。

- 前置知识：第一篇的执行流程、源码结构和基础诊断工具。
- 核心成果：类文件结构图、类生命周期图、加载器与类型关系图。
- 衔接：本篇解释类型和方法信息如何建立；对象实际布局交由第三篇，方法执行和优化交由第四篇。

加载、连接、解析与初始化的规范语义依照[虚拟机规范第 5 章](https://docs.oracle.com/javase/specs/jvms/se25/html/jvms-5.html)，HotSpot 内部缓存与元数据布局作为实现内容分析。

## 第 4 章 类文件结构与信息表达

**核心问题：类文件怎样保存虚拟机运行所需的结构、类型和行为信息？**

### 4.1 类文件总体结构

- 4.1.1 按读取顺序说明魔数、版本、常量池、访问标志、继承关系及成员信息。
- 4.1.2 区分类文件格式版本、预览特性标记和运行时兼容性，解释版本错误的形成条件。

### 4.2 常量池、描述符与成员表

- 4.2.1 区分字面量、符号引用及其索引关系，展开字段和方法描述符。
- 4.2.2 对照字段表、方法表与泛型签名，说明运行时类型描述和源码泛型信息的不同用途。

### 4.3 方法代码与相关属性

- 4.3.1 展开 `Code` 的局部变量容量、操作数栈深度、指令数组和异常表。
- 4.3.2 关联 `StackMapTable`、行号及局部变量调试信息，解释验证、定位和调试各自依赖的数据。

### 4.4 现代语言结构的类文件表达

- 4.4.1 说明注解、记录类、密封类和嵌套关系如何表达，并区分编译器生成结构与专用属性。
- 4.4.2 将类文件中的信息对应到反射可见性、访问控制及虚拟机执行需求。

### 4.5 类文件处理接口

- 4.5.1 介绍类文件应用程序编程接口（Application Programming Interface，API），即 Class-File API 的模型、读取和遍历方式。
- 4.5.2 规划生成与变换案例，说明常量池和栈映射处理如何影响类文件合法性，避免将“能生成”当成“语义正确”。

**图解安排：**类文件结构图、常量池索引关系图、方法代码与属性对应图。

## 第 5 章 字节码指令与验证机制

**核心问题：虚拟机怎样确认一段字节码能够按类型规则安全执行？**

### 5.1 操作数栈与局部变量

- 5.1.1 以方法参数、临时值和返回值说明栈效果与局部变量槽的用途。
- 5.1.2 说明不同类别数值的槽使用规则、局部变量复用和方法描述符之间的联系。

### 5.2 运算、控制流与数组

- 5.2.1 展开算术、类型转换、条件分支、循环及分支汇合处的状态。
- 5.2.2 解释数组类型、元素访问和运行时检查，并对照密集与稀疏选择分支的表达。

### 5.3 调用、异常与同步

- 5.3.1 将主要调用指令与接收者、参数、返回值及后续解析步骤对应。
- 5.3.2 对照异常表、`athrow`、同步指令与同步方法标志，说明正常与异常退出路径。

### 5.4 验证器的工作过程

- 5.4.1 区分格式检查、静态约束、结构约束和类型状态检查。
- 5.4.2 用控制流图说明验证类型传播、栈映射帧和分支汇合，解释不合法状态如何被识别。

### 5.5 未初始化对象与构造器

- 5.5.1 追踪 `new` 产生的未初始化引用与构造器调用后的类型状态变化。
- 5.5.2 结合 JDK 25 灵活构造器体，区分源码允许的构造前置操作与字节码验证所要求的约束。

**图解安排：**逐指令栈变化表、控制流与验证状态图、对象初始化状态图。

## 第 6 章 类加载器、命名空间与模块

**核心问题：为什么相同名称的类可能是不同类型，模块访问规则又在哪里介入？**

### 6.1 内建类加载器

- 6.1.1 说明启动、平台和应用类加载器的职责及模块化运行时下的关系。
- 6.1.2 区分类、资源与模块的发现路径，以及启动加载器的特殊表示。

### 6.2 委派与自定义加载

- 6.2.1 串联已加载查询、委派、查找、定义和链接请求，分析加载锁及并行加载。
- 6.2.2 讨论父优先和自定义策略的适用条件，说明委派策略与类型安全约束的区别。

### 6.3 类身份与加载约束

- 6.3.1 区分定义加载器和发起加载器，用二进制名称及定义加载器描述类型身份。
- 6.3.2 通过跨加载器方法签名和类型转换案例解释加载约束、类冲突与隔离边界。

### 6.4 线程上下文加载器与服务发现

- 6.4.1 分析框架代码如何找到应用提供的服务实现，以及上下文加载器的设置和恢复。
- 6.4.2 关联服务发现、线程长期存活与加载器被持有的问题，为类卸载分析铺垫。

### 6.5 模块可访问性

- 6.5.1 区分模块可读性、包导出和反射开放，说明模块身份与加载器身份的关联。
- 6.5.2 规划模块层、未命名模块及访问失败案例，区分找不到类与找到后不可访问。

**图解安排：**加载请求流程图、双加载器类型身份图、模块访问判定图。

## 第 7 章 连接、解析与初始化

**核心问题：一个类从被找到到可以执行，其状态如何变化，失败又如何保留？**

### 7.1 各阶段的职责与时机

- 7.1.1 分离验证、准备、解析和初始化，说明阶段之间的依赖及解析时机的灵活性。
- 7.1.2 区分加载成功、链接成功和初始化成功，建立错误定位的阶段坐标。

### 7.2 符号引用解析

- 7.2.1 分别追踪类、字段和方法符号引用的查找、访问检查与运行时关联。
- 7.2.2 区分解析所得结果与实际接收者决定的调用目标，连接第四篇的方法分派分析。

### 7.3 静态字段与类初始化方法

- 7.3.1 对照默认值、常量属性和 `<clinit>` 中的赋值，解释准备与初始化承担的不同工作。
- 7.3.2 以常量变量读取和普通静态字段读取对照初始化触发条件。

### 7.4 初始化并发、递归与失败

- 7.4.1 推演父类及相关接口初始化、同线程递归请求和多线程竞争初始化的状态变化。
- 7.4.2 说明初始化锁、失败状态和后续访问行为，并分析初始化相互依赖造成的阻塞。

### 7.5 链接错误与兼容性

- 7.5.1 以缺失类、缺失方法、访问权限变化和成员形态变化定位链接失败阶段。
- 7.5.2 区分源码兼容、二进制兼容和行为兼容，分析类库升级与加载器隔离的影响。

**图解安排：**类状态迁移图、静态字段赋值时间线、并发初始化时序图。

## 第 8 章 HotSpot 类型系统与运行时元数据

**核心问题：类文件信息怎样转化为运行时可查找、可调用、可回收的结构？**

### 8.1 类型结构与类镜像

- 8.1.1 关联 `Klass`、`InstanceKlass`、数组类型、堆中实例与 Java `Class` 镜像。
- 8.1.2 区分元数据所在区域与类镜像所在区域，解释类型信息的双向关联。

### 8.2 字段、方法与常量池元数据

- 8.2.1 从字段描述到布局信息，从方法字节码到运行时方法表示。
- 8.2.2 说明解析前后的常量池信息、缓存用途及其与解释器和编译器的关系。

### 8.3 子类型与接口检查

- 8.3.1 分析类继承、接口实现和数组类型关系在检查过程中的作用。
- 8.3.2 介绍快速路径、辅助结构与缓存如何减少重复查找，说明实现策略不改变类型规则。

### 8.4 隐藏类

- 8.4.1 解释隐藏类的定义方式、查找边界以及运行时生成机制的使用场景。
- 8.4.2 对照普通类和隐藏类的生命周期，关联动态调用实现而不提前展开调用优化。

### 8.5 元数据持有与类卸载

- 8.5.1 建立加载器数据、类镜像、方法元数据和运行时持有者的关系图。
- 8.5.2 说明卸载资格、垃圾收集协作和实际回收时机；分析线程、缓存及本地持有造成的存活。

**图解安排：**类型元数据对象图、符号引用到运行时结构映射图、加载器存活关系图。
