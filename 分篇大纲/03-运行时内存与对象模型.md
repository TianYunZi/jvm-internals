# 第三篇 运行时内存与对象模型

《jvm原理》分篇大纲，覆盖第 9—12 章。基于 Java 开发工具包（Java Development Kit，JDK）25，以 HotSpot 解释 Java 虚拟机（Java Virtual Machine，JVM）的进程内存组成、对象表示和资源生命周期。章、节编号与[全书大纲](../大纲.md)对应。

## 本篇目标与前后衔接

本篇沿“规范内存区域 → 进程实际占用 → 对象布局 → 分配访问 → 元空间与本地资源”展开。读者应能够计算对象空间成本，解释堆统计与进程占用的差异，并判断内存问题属于哪个生命周期。

- 前置知识：第二篇的类型元数据、类镜像与加载器关系。
- 核心成果：进程内存账本、对象布局图、对象分配路径图。
- 衔接：分配消除只介绍现象与内存效果，优化过程由第四篇展开；回收过程由第五篇展开。

运行时区域的语义依据[虚拟机规范第 2 章](https://docs.oracle.com/javase/specs/jvms/se25/html/jvms-2.html)。元空间、代码缓存及具体对象头属于 HotSpot 实现层的分析对象。

## 第 9 章 运行时数据区与进程内存

**核心问题：应用的内存究竟花在哪里，为什么堆大小不能代表整个进程？**

### 9.1 规范定义的运行时数据区

- 9.1.1 按线程私有与线程共享组织程序计数器、栈、堆、方法区和运行时常量池。
- 9.1.2 区分逻辑职责与物理布局，说明规范没有为所有实现规定同一组内存分区。

### 9.2 HotSpot 的实际内存组成

- 9.2.1 建立 Java 堆、元空间、代码缓存、线程栈和内部本地结构的分类账本。
- 9.2.2 说明类镜像、静态字段、字符串与类型元数据各自的持有关系及存储位置。

### 9.3 预留、提交与驻留

- 9.3.1 区分虚拟地址预留、内存提交、页面触碰和驻留集大小（Resident Set Size，RSS）。
- 9.3.2 分析共享映射、按需分配和页面回收对工具读数的影响，确定比较所需的统计口径。

### 9.4 堆、进程与容器预算

- 9.4.1 从堆上限推导还需预留的线程栈、元数据、代码和本地库空间。
- 9.4.2 对照进程视角与容器限制，说明容器终止和 Java 内存异常可能来自不同机制。

### 9.5 内存不足与栈溢出

- 9.5.1 按堆、元空间、线程资源和直接内存等线索分类异常信息。
- 9.5.2 区分分配失败、资源上限、持续保留和调用栈耗尽，建立后续诊断所需的问题树。

**图解安排：**规范区域与实现区域对应图、进程内存预算图、异常分类决策图。

## 第 10 章 对象布局、压缩指针与紧凑对象头

**核心问题：一个对象为何占用这些字节，对象头压缩又影响哪些运行机制？**

### 10.1 普通对象与数组的组成

- 10.1.1 分解对象头、字段数据、数组长度和对齐填充，给出逐项估算方法。
- 10.1.2 说明继承字段、字段重排和对齐对布局的影响，并区分对象自身大小与可达对象总大小。

### 10.2 对象头中的运行时信息

- 10.2.1 分析类型定位、身份哈希、年龄与锁状态信息的职责。
- 10.2.2 说明不同状态下信息如何编码或转移，为第六篇的锁机制预留接口。

### 10.3 两类压缩指针

- 10.3.1 分别说明对象引用和类型指针的压缩目标、编码和解码过程。
- 10.3.2 分析地址基址、位移、对象对齐和堆规模之间的关系，避免用单一容量阈值概括所有配置。

### 10.4 紧凑对象头设计

- 10.4.1 对照传统与紧凑布局，说明压缩类型信息和保留运行时状态的设计取舍。
- 10.4.2 追踪紧凑对象头对锁路径、身份哈希、对象移动和回收器协作提出的要求。

### 10.5 JDK 25 配置与空间估算

- 10.5.1 比较默认配置和显式启用紧凑对象头的配置，记录实际生效的参数组合。
- 10.5.2 对普通对象、继承对象和数组估算空间变化，解释对齐可能吸收部分头部节省。

JDK 25 的紧凑对象头是产品特性，默认关闭；布局比较须明确是否启用 `UseCompactObjectHeaders`。[官方参数说明](https://docs.oracle.com/en/java/javase/25/docs/specs/man/java.html)

**图解安排：**普通对象与数组布局图、压缩引用解码图、两种对象头配置对照图。

## 第 11 章 对象分配、初始化与访问

**核心问题：一次源码中的对象创建如何转化为内存操作，又可能在哪里被消除？**

### 11.1 分配快路径与慢路径

- 11.1.1 串联类型准备、大小确定、空间申请和运行时辅助调用。
- 11.1.2 区分解释执行与编译后代码的分配路径，说明空间不足如何进入慢路径。

### 11.2 线程本地分配缓冲区

- 11.2.1 解释线程本地分配缓冲区（Thread-Local Allocation Buffer，TLAB）的指针推进与线程隔离。
- 11.2.2 分析缓冲区补充、剩余空间和缓冲区外分配，区分分配位置与对象是否线程私有。

### 11.3 对象初始化与安全发布

- 11.3.1 区分空间清零、对象头设置、实例字段赋值和构造器方法执行。
- 11.3.2 解释对象可被访问、构造完成和跨线程安全发布的不同条件，连接第六篇的内存模型。

### 11.4 字段、数组与字符串访问

- 11.4.1 从对象引用和字段偏移解释读写，从数组起始位置与索引解释元素定位。
- 11.4.2 分析字符串的内部存储、驻留与去重，区分共享字符存储和共享字符串对象。

### 11.5 分配消除与对象物化

- 11.5.1 用逃逸分析和标量替换的结果解释“源码存在创建表达式，但运行时未分配对象”的情形。
- 11.5.2 说明去优化时的对象重建，区分逻辑对象、被消除的分配与实际堆对象，避免泛化为普遍的栈上分配。

**图解安排：**对象创建阶段图、TLAB 分配与补充图、逻辑对象到物理表示关系图。

## 第 12 章 元空间与本地内存管理

**核心问题：离开 Java 堆之后，谁负责资源的分配、持有和回收？**

### 12.1 元空间分配与回收

- 12.1.1 从类加载器生命周期解释元数据分配单元、类空间和共享管理结构。
- 12.1.2 区分类卸载、空间内部复用和归还操作系统，分析碎片及高水位现象。

### 12.2 运行时内部内存成本

- 12.2.1 汇总线程栈、编译代码、编译活动、运行时表和回收器辅助结构。
- 12.2.2 讨论线程数、类数量、方法编译程度及堆规模变化时各项成本的变化。

### 12.3 直接缓冲区与本地分配

- 12.3.1 区分堆中的包装对象、本地内存块、共享视图和真正拥有释放责任的对象。
- 12.3.2 分析缓存、切片、异步操作和本地库持有如何延长资源生命周期。

### 12.4 本地内存跟踪

- 12.4.1 介绍本地内存跟踪（Native Memory Tracking，NMT）的分类、汇总和差异观察。
- 12.4.2 对照 NMT 与操作系统统计的覆盖范围，解释未被跟踪的本地分配和驻留口径差异。

### 12.5 释放策略与泄漏

- 12.5.1 对照显式关闭、清理机制和进程退出，说明及时释放与最终可回收之间的差异。
- 12.5.2 按拥有者、持有者、释放触发点追踪泄漏，并为第七篇的外部内存生命周期建立基础。

**图解安排：**元空间与加载器生命周期图、包装对象与本地资源所有权图、NMT 与进程统计覆盖图。

## 实验选题与证据安排

| 章节 | 实验选题 | 需保留的证据 | 解释边界 |
| --- | --- | --- | --- |
| 第 9 章 | 堆统计与进程占用对照 | 堆容量、已用量、进程映射、RSS | 同时刻且同口径的数据才适合比较 |
| 第 10 章 | 两种对象头下的布局 | 生效参数、Java Object Layout（JOL）版本与输出 | 工具支持、架构和对齐会影响观察 |
| 第 11 章 | 分配路径与分配消除 | 编译信息、分配采样、缓冲区统计 | 缺少采样记录不能单独证明零分配 |
| 第 12 章 | 本地内存增长分类 | NMT 基线与差异、类和线程数量、进程统计 | NMT 不能覆盖所有第三方本地分配 |

实验尚属正文选题，解释结论时必须同时记录运行阶段、采样方式和内存统计口径。
