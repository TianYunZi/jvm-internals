# 第35章有界故障案例

2026-11-03，Asia/Shanghai。Java开发工具包（Java Development Kit，JDK）25.0.5.0.2、macOS AArch64。用户明确授权有界内存增长、有限忙等和可退出锁等待代码／运行；三种独立进程均退出0。没有内存耗尽、本地崩溃、无限压力或容器终止。

- CH35-E01 memory，进程83495：24个256千字节数组，共6,291,456字节；约三秒与八秒各采类直方图。byte数组总量6,791,504→499,720字节。命令请求回收的干扰在memory-gc.log可追溯；不声称这是无干扰连续存活统计，也未做对象支配树。本地内存跟踪（Native Memory Tracking，NMT）、系统驻留采样与原始输出在本目录。
- CH35-E02 cpu：五秒截止，两次Thread.print与系统采集，加profile飞行记录。cpu-hot-methods.txt共432样本全部BoundedSymptoms.cpu。支持该窗口持续计算；单次栈不足以证明同样结论。原始cpu.jfr、线程栈、系统数据都保留。
- CH35-E03 locks：两线程各先持一锁，使用四秒tryLock逆序等待；locks-stack.txt报告一个Java级死锁，列出左右锁及拥有者。随后超时打破环并释放锁，线程正常退出。存在时点环不等于永久死锁；超时退出是教学收尾，不是锁顺序根因修复。

本地内存跟踪（Native Memory Tracking，NMT）不包含整个进程的所有分配。容器与崩溃按用户同意采用官方历史案例和锁定实现分析；没有伪造本机hs_err或cgroup输出。真实补充环境复核仍保留。
