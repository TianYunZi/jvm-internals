## 观察与边界

- 持有时切片容量1，直接池数量1、容量与内存均8388608字节。另有Arena分配262144字节、24个独立Disposable实例、4线程；所有URLClassLoader的文件资源在构造时已关闭，但实例仍持有类型。
- held-loaders有24个URLClassLoader的各1类，合计工具全局1308类；这与程序的Java类计数范围不同。held-threads显示4个native-holder-*在CountDownLatch限时停放。
- Other持有时8450KB、较初始+8450KB；释放后2KB、较初始+2KB。用途与8MiB直接块、256千二进制字节（kibibyte，KiB）外部块等一致，但没有把整个类别独占归于一个对象。
- Thread持有时比初始+4，栈预留+2048KB、提交+320KB；释放后NMT线程较初始+1，不能把所有全局变化只归给教学线程。
- 请求后有24行Disposable卸载，直接池归零。垃圾收集（Garbage Collection，GC）事件元空间1343K(1600K)→1310K(1536K)；NMT Metaspace类别提交仍较初始+394KB。卸载、内部复用与归还系统不同。
- 堆used3894K→6270K→1797K；ps驻留集大小（Resident Set Size，RSS）56352→67648→67712（1024字节单位），vmmap footprint35.0M→39.0M→35.3M。不同口径分开，不精确相减定位泄漏。

正常关闭Arena、解除持有链、线程退出、具体卸载与直接池清理都有本轮证据；不能保证任意配置同一时点发生。没有访问已关闭段、第三方本地分配或容器故障，没有证明某个系统分配器缓存就是RSS未降的唯一原因。全部小型原始输出保留在本目录，正文与三图引用位置由来源索引对应。
