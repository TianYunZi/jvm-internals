## CH36-E04 本地生命周期

每组32次256千字节外部内存，均触及页面。前态同一Arena保留全部到窗口结束，后态每任务关闭。约两秒保存本地内存跟踪（Native Memory Tracking，NMT）基线／持有及系统快照，六秒保存关闭后差异，八秒进程正常结束。

前态Other8192千字节，关闭后-8192；后态快照Other0、峰值256千字节。前态驻留55,408→55,360千字节，后态窗口47,216千字节；不同进程初始化和分配器影响未排除，NMT释放不推出驻留集大小（Resident Set Size，RSS）同比下降。Linux容器预算／终止按用户同意作来源对照，未本机运行。
