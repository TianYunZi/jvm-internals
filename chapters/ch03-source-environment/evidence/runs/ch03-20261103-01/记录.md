## 观察与结论边界

| 材料 | 实际发生 | 不能扩大的结论 |
| --- | --- | --- |
| program.txt、class-load.log | 普通解释配置进程及关闭钩子完成；入口、Payload 等加载记录存在 | 未动态断在该普通进程的分配入口 |
| default-flags.txt | UseTLAB true / default、MaxHeapSize 4294967296 / ergonomic | 独立 -version 进程，不是本章显式 128 MiB 教学进程的有效最大堆 |
| unlocked-flags.txt | 两个 Unlock 参数 command line；诊断／实验参数条目显示 | 没有启用诊断压力参数，解锁不等于开发构建 |
| log-help.txt | 当前标签、级别与装饰说明 | 未记录的事件不能据此认定没发生 |
| lldb.txt 创建断点 | 实际停在 libjvm.dylib 的 JNI_CreateJavaVM；栈有 JavaMain、ThreadJavaMain、pthread 入口 | 源码路径不保证全部函数保留为独立栈帧；同名符号要核对映像 |
| lldb.txt 解析断点 | ClassFileParser::parse_stream ← 解析器构造 ← KlassFactory ← ClassLoader ← SystemDictionary | 位于应用 main-enter 之前，未采集类名参数，不称为 Payload 的指定加载事件 |
| lldb.txt 分配断点 | InterpreterRuntime::_new 入口命中；其下有无普通函数名的代码地址 | 不凭地址猜 Java 类或方法；下游 allocate_instance 关系据源码，不补造本次栈 |
