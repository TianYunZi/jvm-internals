## 结论映射与图

| 结论 | 性质与依据 | 边界 |
| --- | --- | --- |
| 本机页 16384 字节、缓存行 128 字节 | O02 硬件查询 | 不由归档文档的常见值推导 |
| 主线程和工作线程为限时 parking | O02 java-threads.txt、system-threads.txt | 不是完整调度历史；Java 状态与系统分类不机械等同 |
| 堆、NMT 分类与系统驻留不同 | O02 多工具快照、S02 | 非同一瞬间原子采样；不是泄漏判据 |
| 堆分类差额包含本例不可访问前缀 | O02 地址区间交叉定位与 S05 | 推断与实现相互支持；没有观察物理页号 |
| x86-64 与 AArch64 调用、原子和排序实现不同 | S03、S04 | 未实测 x86-64、未作性能比较 |
| 编译器屏障不必产生硬件指令 | S04 的 compiler_barrier 实现 | 不能因此从程序中随意移除顺序约束 |
