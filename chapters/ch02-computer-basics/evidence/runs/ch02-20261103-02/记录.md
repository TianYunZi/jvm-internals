## 对应与限制

- ps 的 RSS=59248、VSZ=490639248，手册规定对应单位为 1024 字节；vmmap 的 physical footprint=37.5M 与 RSS 归账口径不同。
- vmmap 的 385.0G Guard 区域驻留为 0，直接说明虚拟范围不能当作同量物理内存消耗；这是该进程与系统状态，不是所有 Java 进程的固定布局。
- 收集器报告堆范围 [0x126000000,0x12e000000)、预留 131072K、提交 34816K、已用 5594K。NMT 的 Java Heap 预留 [0x125800000,0x12e000000) 共 139264KB；vmmap 显示前缀 8192K 不可访问。区间、工具分类与对象已用量分开解释。
- main 和 journey-worker 均在 CountDownLatch 上限时 parking，Java 状态 TIMED_WAITING；系统线程状态使用自身的 S 等分类，不能强行等同。
- jcmd help 确认目标进程实际支持的命令，可由 CH03 明确复用；VM.info 提供版本、运行状态和本地环境，未把每个动态条目都当作正文结论。

这些采集发生在相邻时点，附加操作本身会引入线程、加载与其他状态变化；NMT 是跟踪分类，不是全进程实际驻留的替代物。未读取物理页号，未做 x86-64 实测、压力或性能比较。没有编写测试／验证脚本或一次性断言。
