48:// Layout of metadata bits in colored pointer / zpointer.
49-//
50-// A zpointer is a combination of the address bits (heap base bit + offset)
51-// and two low-order metadata bytes, with the following layout:
52-//
53-// RRRRMMmmFFrr0000
54-// ****               : Used by load barrier
55-// **********         : Used by mark barrier
56-// ************       : Used by store barrier
57-//             ****   : Reserved bits
58-//
59-// The table below describes what each color does.
60-//
61-// +-------------+-------------------+--------------------------+
62-// | Bit pattern | Description       | Included colors          |
63-// +-------------+-------------------+--------------------------+
64-// |     rr      | Remembered bits   | Remembered[0, 1]         |
65-// +-------------+-------------------+--------------------------+
66-// |     FF      | Finalizable bits  | Finalizable[0, 1]        |
67-// +-------------+-------------------+--------------------------+
68-// |     mm      | Marked young bits | MarkedYoung[0, 1]        |
69-// +-------------+-------------------+--------------------------+
70-// |     MM      | Marked old bits   | MarkedOld[0, 1]          |
71-// +-------------+-------------------+--------------------------+
72-// |    RRRR     | Remapped bits     | Remapped[00, 01, 10, 11] |
73-// +-------------+-------------------+--------------------------+
74-//
75-// The low order zero address bits sometimes overlap with the high order zero metadata
76-// bits, depending on the remapped bit being set.
77-//
78-//             vvv- overlapping address and metadata zeros
