## 观察与图

| 结论 | 性质和依据 | 边界 |
| --- | --- | --- |
| Object 启动、Driver 平台、应用 app；资源有 jrt／file 地址 | O01 identity.txt | 本轮具体版本；资源地址不决定类型身份 |
| 同名 true、同类型 false；echo 参数定义者不同 | O01 identity.txt、plugin.javap.txt、S02 | 两类由同一份字节分别定义；描述符相同不推出相同解析类型 |
| relay 发起请求取得 left 定义的同一类型 | O01、S01／S02 | 不把请求入口当成新定义；加载器名称不是身份判据 |
| 跨 Plugin 转换失败 | 已授权故障观察 O01 | 不是动态观察到加载约束冲突 |
| 提供者由子方定义、服务接口由 app 共享，上下文恢复 | O01 service.txt、S03 | 未制造长期线程池泄漏，资源关闭不等于卸载 |
| class found、read true，公开访问仍可失败 | O01 模块基线、S05 | 查找成功与访问成功分开；一般反射假定可读性 |
| exports 仅允许本例公开调用，opens 允许本例私有反射 | O01 三配置、S05 | 独立短进程，不改写源描述符；isExported 开放时也为 true |
| 未命名调用方建立子层，库只在子层 | O01 layer.txt、S04 | 本轮根模块选择；不泛化所有层都采用一个加载器 |
